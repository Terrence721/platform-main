The Helpdesk app is where the 13 modules do real work together. This page shows how its five projects depend on each other and on the modules: only the Angular app reaches into NgRx, it shares only a contract of types and rules with the API (its in-browser demo also reuses the back end's services), and the end-to-end suite stands on top of both. Every edge below was counted from the projects' own import statements on 2026-10-10. The module dependency graph shows how the modules depend on each other.

What Each Project Is

helpdesk

  • The Angular app: a page per role, reports, live updates, sounds
  • The only project that imports NgRx: a signal store per page, the NgRx store and effects for the session, landing page and router state
  • Its in-browser demo imports helpdesk-server's real services and runs them against PGlite, with no server at all

helpdesk-api

  • NestJS: sign-in with a JWT cookie and role guards
  • One module per feature; each controller hands the work to helpdesk-server
  • Shares nothing with the app except the contract

helpdesk-server

  • The services, the Drizzle schema and migrations, and the seed data
  • No HTTP of its own, which is why the same code also runs in the browser for the demo

helpdesk-contract

  • Tickets, roles, the ticket workflow, live events and report shapes
  • Imports nothing at all, so every other project can depend on it without pulling anything else in

helpdesk-e2e

  • Playwright tests against the real Docker Compose stack, run on every pull request
  • Imports only the contract's types; Nx's implicit dependencies make it run after helpdesk and helpdesk-api
How these edges were found: every @ngrx/* and @helpdesk/* import in each project's source, with specs counted separately (that is where store/testing and effects/testing appear). The two tooling modules show up nowhere in the code: eslint-plugin is loaded by the app's eslint.config.mjs, and schematics generated the landing page's state once (nx g @ngrx/schematics:entity). Three pieces planned for the app were never needed and aren't imported: concatLatestFrom, router-store/data-persistence and signals events.
