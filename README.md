# platform-main

A demonstration NgRx + Nx workspace, built up incrementally as a practice/reference project.

This repo is **not affiliated with, and not published by, the upstream [@ngrx/platform](https://github.com/ngrx/platform) project**. It borrows the same workspace layout and tooling conventions (Nx, Angular, the `@ngrx/*` package split) purely as a learning/demo structure.

## Getting started

```shell
yarn install
yarn nx report
```

See [CONTRIBUTING.md](./CONTRIBUTING.md) for development setup and testing commands.
